# スタレ ガチャ計画プランナー

崩壊：スターレイルの「次のピックアップに、いまの貯蓄で間に合うか」に答える単体 HTML ツール。
手持ちの星玉と目標日までに貯まる見込みから、引ける確率・不足連数・いつまで待てば確定かを出します。

非公式のファンツールです。HoYoverse とは関係ありません。作者: ユニフ

## 動作確認

- テスト: `node --test tests/`
- 画面: `python -m http.server 8000` を実行して `http://localhost:8000/` を開く

## 計算の前提

- 5★ 排出率: 1〜73 連目 0.6%、74 連目から 1 連ごとに +6%、90 連目で 100%
- ピックアップキャラは 50%。すり抜けたら次の 5★ は確定
- 確定に必要な連数: 保証あり 90 − 天井、保証なし 180 − 天井
- 1 連 = 星玉 160。収入は週 ÷7、バージョン（42 日）÷42 で 1 日あたりに換算
- 「いまのガチャで使う連数」が 1 以上のときは、そのキャラを引き切った前提で目標ガチャを天井 0・保証なしから計算

## 収入の初期値について

初期値は目安です。ゲーム内の実装値と食い違うことがあるので、自分の実績に合わせて「5. 収入の目安」を直してください。
